# Code of conduct

Dumb TV Clean follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. Many
people here are running a terminal for the first time to fix their own TV; help
them the way you would want to be helped.

Dumb TV Clean is maintained by [Vinay Sajjanapu](https://github.com/vinaysajjanapu).
To report a problem, open an issue on this repository, or a private report from
the repository's **Security** tab. Reports are kept confidential.
